Описание
Проект направлен на автоматизацию процессов учета книг, читателей и операций выдачи/возврата в библиотеке.
Основные функции:
Управление книгами: добавление, редактирование, удаление книг и отслеживание их статуса (доступна/выдана).
Управление читателями: регистрация новых пользователей, учет их данных.
Операции выдачи/возврата: запись фактов выдачи и возврата книг, контроль сроков.
Две версии интерфейса:
Администратор: полный доступ ко всем функциям и данным.
Пользователь: ограниченный доступ (например, поиск книг, просмотр своих текущих книг).
